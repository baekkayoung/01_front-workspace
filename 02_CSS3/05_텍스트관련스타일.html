text_decoration : 텍스트에 줄을 긋거나 줄을 없앨 때 사용

    선택자{
        text-decoration : nono | underline | overline | line-through;
    }

text-transform : 영문 텍스트에 대소문자 변환시 사용

        선택자{
            text-transform : uppercase | lowercase | capitalize
        }


    
    
    
        
  1. uppercase : 영문자를 다 대문자로

  2. Lowercase : 영문자를 다 소문자로
    3. 
        
  3. capitalize : 영문자의 first text만 대문자로 변환
