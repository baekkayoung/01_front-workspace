이벤트1(Event)

* 고전 이벤트 (기본 이벤트 모델)

특정 요소 객체를 가지고 와서 해당 요소의 이벤트 속성에 접근한 후
이벤트 핸들러를 연결하는 방식
이벤트를 제거 할 수도 있음


* 인라인 이벤트 모델

요소 내부에 직접적으로 이벤트 속성을 제시해서 실행할 내용을 정의하는 방식
주로 script 태그 내에 정의 돼있는 함수 호출하는 방식 주로 사용


* 표준 이벤트 모델 (addEventListener)

w3c에서 공식적으로 지정한 이벤트 모델
IE는 9버전 부터 지원

2. 현재 이벤트가 발생하나 해당 요소객체에 접근하는 방법

3. 태그별로 기본적으로 가지고 있는 이벤트 제거

기본적으로 이벤트를 가지고 있는 요소
- a태그 : 클릭시 href에 제시되어 있는 url로 요청하는 기본이벤트 보유 - form내의 submit 버튼 : 클릭시 사용자가 입력한 값들을 action에 제시되어있는 url로 제출하면서 요청하는 기본이벤트보유

태그내에 기본적으로 설정되어 있는 이벤트가 실행 안되게끔 막고 싶음
=> 이벤트 핸들러의 return 값을 false로 하면 기본이벤트 실행 안됨
