* each 메소드

배열에 모든 인덱스에 순차적으로 접근하고자 할 때,
객체가 가지고 있는 모든 속성에 순차적으로 접근하고자 할 때
사용하는 for in문과 유사하게 수행되는 메소드 

        1)$.each(객체|배열, function([매개변수1, 매개변수2]){
            순차적으로 접근할 때 마다 실행할 내용;
        }); 

        2) 객체 | 배열.each(function([매개변수1, 매개변수2]){ 콜백함수..
            순차적으로 접근할 때 마다 실행할 내용;
        });
        
        * 만약 객체를 제시했다면
        첫번째 매개변수에는 순차적으로 접근할 때 마다 속성명(key)이 담김
        두번째 매개변수에는 해당 속성값(value)이 담김

        * 만약 배열을 제시했다면
        첫번째 매개변수에는 순차적으로 접근할 때마다 인덱스 수가 담김
        두번째 매개변수에는 해당 인덱스 값이 담김

        => for in문은 인덱스 값은 알 수 없고, 인덱스 수만 알 수 있음
