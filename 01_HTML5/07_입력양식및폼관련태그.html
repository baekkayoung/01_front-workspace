폼 관련 태그

form태그 내에 submit이라는 버튼 클릭시 해당 form 안에 작성된
사용자가 사용한 값을 서버로 넘기면서 요청하는 역할 수행
form action="" method=""

* action 속성 : 해당 form에 사용자가 입력한 값을 전달하면서 요청할 서버의 경로 제시
* method 속성 : 요청 전송 방식을 지정하는 속성 (get(기본값)/post)
> get 방식 : 요청시 사용자가 입력한 값들이 url에 노출되는 방식
> post 방식 : 요청시 사용자가 입력한 값들이 url에 노출되지 않는 방식
form 내에 submit 버튼클릭시 action 지정한 서버로 사용자가 입력한 값들이 넘어가면서 요청이 됨 (사용자가 입력한 값들은 항상 key=value 세트로 전달)

라디오 버튼과 체크박스 관련 input 태그의 타입

라디오 버튼(type="radio")

-제시한 여러개의 값들 중에서 오로지 한 개만 선택해야 될 때
(name 속성 값이 똑같은 것들 끼리 하나의 그룹으로 지어짐)
-제출시 현재 선택된(checked) 라디오 버튼의 value값이 넘어감

성별 :

체크박스(type="checkbox")

- 제시한 여러개의 값들 중에서 여러개 선택할 경우
- 제출시 현재 선택된(checked) 체크박스의 value 값 넘어감

selcet 태그와 option 태그

-사용자에게 직접 키보드로 값을 입력받는 게 아니라
내가 제시한 여러개의 옵션(목록)들 중에서 선택할 수 있게끔
-제출시 현재 선택된(selceted) option의 값이 넘어감
-각각의 option에 value값을 명시하지 않았을 경우 content 영역의 값이 넘어감
-value 값을 명시했을 경우 value 값이 넘어감
